<p dir="auto"><strong>English</strong></p>
<p dir="auto">About the Project</p>
<p dir="auto">Gift &amp; Referral Bot is an open-source Telegram bot designed to manage referral links, track invited users, and reward users with Telegram gifts.</p>
<p dir="auto">Features</p>

<ul dir="auto">
 	<li><strong>🔗 Personal referral link for each user</strong></li>
 	<li><strong>👥 Track invited and referred users</strong></li>
 	<li><strong>🎁 Reward users based on successful referrals</strong></li>
 	<li><strong>🧸 Telegram gift rewards</strong></li>
 	<li><strong>📊 Referral and user statistics</strong></li>
 	<li><strong>🤖 Telegram bot-based interface</strong></li>
 	<li><strong>⚙️ Configurable through environment variables</strong></li>
 	<li><strong>🗄️ SQLite database for storing users and referral data</strong></li>
</ul>
<p dir="auto">How It Works</p>
<p dir="auto">Users receive a unique referral link and can share it with friends, groups, or channels. Successful invitations are tracked automatically, and users can receive rewards after reaching the required referral milestone.</p>
<p dir="auto">Configuration</p>
<p dir="auto">Sensitive information such as the Telegram Bot Token and Admin ID should be stored in .env and must never be committed to GitHub.</p>

<p dir="auto"><strong>فارسی</strong></p>
<p dir="auto">درباره پروژه</p>
<p dir="auto">ربات دعوت و گیفت یک پروژه متن‌باز برای تلگرام است که برای مدیریت لینک‌های دعوت، ثبت کاربران دعوت‌شده و پاداش دادن به کاربران با گیفت‌های تلگرام طراحی شده است.</p>
<p dir="auto">امکانات</p>

<ul dir="auto">
 	<li>🔗 <strong>لینک دعوت اختصاصی برای هر کاربر</strong></li>
 	<li><strong>👥 ثبت و مدیریت کاربران دعوت‌شده</strong></li>
 	<li><strong>🎁 پاداش بر اساس تعداد دعوت‌های موفق</strong></li>
 	<li><strong>🧸 اهدای گیفت تلگرام</strong></li>
 	<li><strong>📊 نمایش آمار دعوت‌ها و کاربران</strong></li>
 	<li><strong>🤖 رابط کاربری مبتنی بر ربات تلگرام</strong></li>

<p dir="auto">نحوه عملکرد</p>
<p dir="auto">هر کاربر یک لینک دعوت اختصاصی دریافت می‌کند و می‌تواند آن را برای دوستان، گروه‌ها یا کانال‌ها ارسال کند. دعوت‌های موفق به‌صورت خودکار ثبت می‌شوند و پس از رسیدن کاربر به تعداد دعوت موردنیاز، پاداش برای او در نظر گرفته می‌شود.</p>
<p dir="auto">تنظیمات</p>
<p dir="auto">اطلاعات حساس مانند توکن ربات و شناسه ادمین باید در فایل .env قرار داده شوند و نباید در GitHub منتشر شوند.</p>
